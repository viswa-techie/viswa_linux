Below is a **comprehensive master guide (Table of Contents)** for the **major Linux Kernel Frameworks** similar to **Video4Linux2**.

This is structured like the earlier kernel subsystem guides: **beginner → advanced**, covering **architecture, drivers, APIs, flows, debugging, and embedded use cases**.

This guide focuses on the **most important Linux frameworks used in real systems**:

* Video
* Audio
* Display/GPU
* Input devices
* I2C / SPI
* GPIO
* USB
* Networking
* Power / Clocks / Regulators
* DMA

These frameworks form the **core device infrastructure of Linux**.
